🌊 Oceanography Context

Foundation

🗺️ Study Area: Indonesian Straits

The project focuses on two key Indonesian straits that are part of the Indonesian Throughflow (ITF) — one of the most important ocean current systems on Earth.

🌊 Sunda Strait (Bada site)

105.8–106.0°E, 6.0–5.8°S
  • Located between Java & Sumatra islands
  • Clear stream-like flow (bidirectional SW/NE)
  • Dominant tidal pattern: Diurnal (24h period)
  • Main flow: SW direction (March–Nov), NE during Australian monsoon
  • Relatively homogeneous bathymetry

🌊 Lombok Strait (Sega site)

115.5–115.8°E, 8.75–8.47°S
  • Located between Bali & Lombok islands
  • More complex due to Nusa Penida Island bifurcation
  • Dominant tidal pattern: Mixed semi-diurnal (12h period)
  • Two distinct branches: eastern (>115.625°E) and western
  • Part of the main ITF pathway (Pacific → Indian Ocean)

🌊 Indonesian Throughflow (ITF)

The ITF is the only tropical passage connecting two major ocean basins — transporting warm, low-salinity Pacific water into the Indian Ocean.

  • Flows through Indonesian archipelago (Pacific → Indian Ocean)
  • Lombok Strait is a major ITF pathway
  • Affects: regional climate, monsoons, global heat transport
  • Seasonal variability linked to monsoon cycles
  • ITF drives the dominant seasonal (low-frequency) current component
📊
In our data analysis, SSH gradient (Java Sea north vs Indian Ocean south) is a strong predictor of the non-tidal downstream current (R ≈ 0.80)!

🌊 Ocean Current Decomposition

Currents are decomposed into two components for better analysis and modeling:

Classical (U, V) Decomposition

  • U component — East-West velocity (m/s)
  • V component — North-South velocity (m/s)
  • Standard geographic coordinate system
U = east-west velocity (positive = eastward)
V = north-south velocity (positive = northward)

Downstream / Cross-stream (DS, CS)

  • DS — Along the main flow axis of the strait
  • CS — Perpendicular to main flow
  • More physically meaningful for strait dynamics
  • Rotation angle based on median current direction
Rotation angle (Sunda) ≈ 45.21° clockwise from North
Rotation angle (Lombok) ≈ 53.06° clockwise from North

🔬 Tidal vs Non-Tidal Decomposition

Currents are also separated into tidal (high-frequency) and non-tidal (residual) components using filters:

High-pass filter → Tidal signal
(period < 72h: captures tidal oscillations at 12h/24h)
Low-pass filter → Non-tidal signal
(period > 72h: captures slow seasonal/ITF variations)
🔍
Why? After removing tides, the correlation between SSH gradient and the remaining (non-tidal) current jumps from 0.53 to 0.80! This shows that different variables drive different timescales.

📡 HF Radar — What is it?

How it works

  • Transmits radio waves (3–30 MHz) over the sea surface
  • Measures Doppler shift of reflected waves → surface current velocity
  • Coverage: typically up to 200 km radius
  • Output: 2D current field (U and V components)

🔧 How Neural Networks Learn — Step by Step

1. Forward Pass (Prediction)

Input data flows through layers of neurons, each applying:

output = activation(weights × input + bias)

2. Loss Function (Measure Error)

Compare prediction vs. truth:

MSE = (1/n) × Σ(prediction - truth)²

3. Backward Pass (Learn)

Calculate how much each weight contributed to the error using backpropagation (chain rule of calculus)

4. Gradient Descent (Update)

weight = weight - learning_rate × gradient

Repeat for many epochs until loss is minimized!

Key Concepts Explained Simply

ConceptSimple Explanation
EpochOne full pass through all training data
BatchSmall chunk of data processed at once
Learning RateHow big steps are during learning (too big = unstable, too small = slow)
OverfittingModel memorizes training data but fails on new data
UnderfittingModel too simple, can't capture patterns
GradientDirection to adjust weights to reduce error
Activation FunctionAdds non-linearity (ReLU, tanh, sigmoid)

⏱️ Recurrent Neural Networks — Handling Time Series

Normal neural networks can't remember the past. For time series (like ocean currents), we need networks with memory.

🌊
Ocean currents at time t strongly depend on currents at t-1h, t-2h... t-24h. We need the model to "remember" this history!

🔵 LSTM — Long Short-Term Memory

📐 Why LSTM for UC1?

  • Autocorrelation shows currents have 24-hour cyclic pattern → LSTM can capture this
  • Proven best performer in literature (outperforms RF, FFNN, classical methods)
  • Can handle variable-length look-back windows
  • Input shape: (batch_size, lookback_time, features)

🗺️ ConvLSTM — Spatial + Temporal Together

HF Radar gives us a 2D spatial map at each timestep. Regular LSTM ignores spatial structure. ConvLSTM combines convolutions with LSTM gates.

Regular LSTM limitation

Flattens 2D spatial grid → loses spatial relationships between neighboring pixels

# LSTM input shape: # (batch, time, channels × height × width) # Spatial info LOST after flattening

ConvLSTM advantage

Gates use convolutions → preserves 2D spatial structure throughout processing

# ConvLSTM input shape: # (batch, time, channels, height, width) # Spatial info PRESERVED!
🏆
Literature shows: ConvLSTM > CNN-GRU > LSTM for spatiotemporal ocean current prediction (Jingjing Liu, 2022). Adding temporal attention further reduces MAE by 50%+!

📊 Training / Validation / Test Split — Critical Concept

🏋️ Training Set

Data the model learns from. Weights are updated based on this.

~65% of data

✅ Validation Set

Used during training to check generalization and tune hyperparameters. Never used to update weights!

~15% of data

🎯 Test Set

Final evaluation. Only touched once, after training is complete. The true performance metric!

~20% of data
⚠️
Data Leakage Warning! For time series, never use random splitting! Future data must not leak into training. UC1 uses temporal chunks distributed across seasons to ensure diversity without leakage.

Lookback Decision

  • Longer lookback → fewer training samples available

🩹 Gap Filling Strategy

Before training, small gaps in HF Radar data are filled to maximize training samples. This is a preprocessing step, not the main ML task!

Gap Filling Decision Tree
📋 Spatio-temporal gap (few pixels missing):
→ Temporal interp. if gap ≤ 80 min (Sunda) / 50 min (Lombok)
→ Spatial extrapolation (Gauss-Seidel) if still missing but valid neighbors exist
→ Remove timestamp if too large
📋 Temporal gap (entire map missing):
→ Temporal interpolation if gap ≤ 80 min (Sunda) / 50 min (Lombok)
→ Ignore otherwise (these become the ML model's task!)
📊
Sunda: Threshold 80 min → RMSE < 10 cm/s
📊
Lombok: Threshold 50 min → RMSE < 10 cm/s

📏 Data Normalization

Neural networks learn better when all inputs are on similar scales. We use Z-score standardization:

y_normalized = (y - μ) / σ

Why Z-score over Min-Max?

  • Robust to outliers (doesn't compress range due to extremes)
  • Centers data around 0 with unit variance
  • Better for normally distributed data (which our variables are!)

⚠️ Critical Rule

⚠️
Compute μ and σ on TRAINING set only! Then apply the same values to validation and test. Otherwise, you leak information from the future!

📅 Train/Val/Test Splitting Strategy

For time series with seasonal variation, we use temporal chunks distributed across seasons:

TRAINVAL TESTTRAIN VALTEST
Btw Aus+AsianAsian Btw Asian+AusAustralian Btw Aus+AsianAsian
Each seasonal period is represented in all three splits → model trained on all ocean conditions

First 48 hours of each split are removed to prevent information leakage between adjacent chunks.

⏱️ LSTM Architecture for UC1

Architecture design

Input: (batch, lookback, channels × H × W) ↓ Flatten spatial dims LSTM layers (process temporal sequence) ↓ Take last hidden state Conv2D (1×1) decoder ↓ Output: (batch, lead_time, 2, H, W) [2 = U and V current components]

Limitation

Spatial information is lost during flattening. The model treats neighboring pixels as unrelated features.

When LSTM works well

  • Pure time-series prediction with scalar inputs
  • When spatial context is encoded via coordinates (lat/lon)
  • First step before trying ConvLSTM
📐
The LSTM cell state acts like a "conveyor belt" — it carries long-term memory (seasonal patterns) while gate activations handle short-term updates (tidal cycles).

🗺️ ConvLSTM Architecture for UC1

Key innovation vs LSTM

All matrix multiplications inside LSTM gates are replaced with convolutions:

# Regular LSTM gate: f = sigmoid(W_f × [h, x] + b_f) # ConvLSTM gate: f = sigmoid(W_f ⊛ [h, x] + b_f) # ⊛ = convolution operation

Result: hidden state shape is (batch, height, width, hidden) → spatially aware!

Full model pipeline

Input: (B, T, C, H, W)
↓
ConvLSTM layers
Process T timesteps, keep spatial dims
↓
Select last hidden state
(B, hidden, H, W)
↓
[Optional] Temporal Attention
Weight all T outputs
↓
Conv2D decoder
(B, LT×2, H, W) → currents

🔄 Training Approaches

1️⃣ One-Pass Model

Simplest
Input (t₀...t) → Model → Output (t+LT)
  • Direct prediction at fixed lead time
  • Simple to train
  • ❌ Separate model per lead time
  • ❌ Struggles at long horizons

2️⃣ Iterative Model

Medium
Train: predict 1 step
Infer: feed prediction back as input → roll to 24h
  • Train once, infer at any horizon
  • ✅ Flexible lead time
  • ❌ Error accumulation over steps
  • ❌ Train/infer distribution mismatch

3️⃣ Auto-regressive

Most robust
Train: use own predictions as inputs → robust to imperfect inputs
  • Trained on its own outputs → handles imperfect inputs
  • ✅ Best for long horizons
  • ❌ More complex training
  • ❌ Can be unstable

🔁 Residual Learning — A Smart Enhancement

Classical:
Input (past) → Model → Predicted current (full value)
Residual:
Input (past) → Model → Change (Δ) → Add to last known current

Residual learning is especially useful in iterative/auto-regressive settings — errors are smaller when predicting changes rather than absolute values!

📏 Evaluation Metrics

Validation

📐 Eulerian Metrics — Single Component

These metrics compare predicted vs true current at the same time and location (Eulerian framework = fixed point in space).

RMSE — Root Mean Squared Error

RMSE = √(1/n × Σ(y_pred - y_truth)²)
  • Units: same as the variable (m/s for currents)
  • Penalizes large errors heavily (due to squaring)
  • Most commonly reported metric in literature
  • Baseline RMSE: ~30 cm/s (Sunda KNN)

MAE — Mean Absolute Error

MAE = (1/n) × Σ|y_pred - y_truth|
  • More robust to outliers than RMSE
  • Same units as variable
  • Easier to interpret as "average error"

Bias

BIAS = (1/n) × Σ(y_truth - y_pred)
  • Positive bias: model underpredicts
  • Negative bias: model overpredicts
  • Important for operational use (systematic errors)

R² and RSE

R² = 1 - Σ(y_truth - y_pred)² / Σ(y_truth - ȳ)²
RSE = Σ(y_truth - y_pred)² / Σ(y_truth - ȳ)²
  • R² = 1.0: perfect model | R² = 0: predicts mean | R² < 0: worse than mean
  • RSE = 1 - R² (fraction of variance unexplained)

🧭 Vectorial Metrics — Direction & Magnitude

Since currents are vectors (direction + magnitude), component-wise metrics are not enough. We also evaluate the full vector.

Current Direction

DIR = (90 - atan2(u, v) × 180/π) mod 360
RMSE_dir = √(1/n × Σ Δdir²)
where Δdir accounts for circular wrapping (0°=360°)

A model that predicts the right magnitude but wrong direction (e.g., 180° off!) would still look OK on U/V metrics but fail direction RMSE.

Current Magnitude (Norm)

NORM = √(u² + v²)
RMSE_norm = √(1/n × Σ(NORM_pred - NORM_truth)²)

Threshold Accuracy

Accuracy = (1/n) × Σ[NORM_truth ∈ [min,max] = NORM_pred ∈ [min,max]]

Binary metric: "is the current in the right intensity range?" Useful for operational warnings.

🚢 Lagrangian Metrics — Particle Trajectories

Eulerian metrics only compare values at fixed points. But for real applications (search & rescue, oil spill tracking), we care about where things go!

🚢
Lagrangian = follows moving particles through the flow. A model with good Eulerian metrics might still fail at Lagrangian tasks if it misses coherent structures!

NCLS Skill Score

Normalized Cumulative Lagrangian Separation

NCLS = Σ dᵢ / Σ l₀ᵢ (sum of separation distances / sum of observed trajectory lengths)
Skill Score = 1 - NCLS/n if NCLS < n, else 0
(n = tolerance threshold)
  • Score = 1.0: perfect trajectory prediction
  • Score = 0.0: trajectory error equals tolerance threshold
  • Computed for 4 drift durations: 3h, 6h, 12h, 24h

Implementation

  • Particles released from every grid cell, every 10 minutes
  • Tracked using 4th-order Runge-Kutta integration (Parcels library)
  • Pairs that exit the study area are excluded (limitation!)
